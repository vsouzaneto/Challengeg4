## Overview

This project follows **Clean Architecture** with strict layer separation.
Dependencies always point inward: `API -> Services -> Repositories -> DB`.
No layer may import from a layer above it.

```
┌─────────────────────────────────────────┐
│              API Layer                  │  FastAPI routers, DTOs, dependencies
│  api/v1/endpoints/  api/v1/dependencies │
├─────────────────────────────────────────┤
│            Service Layer                │  Business logic, orchestration
│               services/                 │
├─────────────────────────────────────────┤
│          Repository Layer               │  Data access, queries
│             repositories/               │
├─────────────────────────────────────────┤
│             Domain Models               │  SQLAlchemy ORM models
│               models/                   │
├─────────────────────────────────────────┤
│           Infrastructure                │  DB, cache, auth, HTTP, tasks
│           infrastructure/               │
└─────────────────────────────────────────┘
```

## Conventions

### Naming
| Artifact | Convention | Example |
|---|---|---|
| Files | `snake_case.py` | `product_service.py` |
| Classes | `PascalCase` | `ProductService` |
| Routes | kebab-case path | `/product-variants/` |
| Env vars | `UPPER_SNAKE` | `DATABASE_URL` |
| DB tables | plural snake | `products`, `order_items` |

### Error Handling
All domain errors extend `AppException` from `core/exceptions.py`.
Never raise raw `HTTPException` inside services or repositories - use typed exceptions.

```python
# Correct
raise NotFoundException("Product", product_id)

# Avoid
raise HTTPException(status_code=404, detail="Not found")
```

### Dependency Injection
Services receive repositories via constructor. Repositories receive a DB session.
FastAPI wires them via `Depends()` in the endpoint.

```python
def _service(db=Depends(get_db)) -> ProductService:
    return ProductService(ProductRepository(db))
```

## Environment Variables

All configuration lives in `.env` and is validated by `core/config.py`.
Add new variables to the `Settings` class - never use `os.environ` directly in
application code.

```bash
cp .env.example .env
```
