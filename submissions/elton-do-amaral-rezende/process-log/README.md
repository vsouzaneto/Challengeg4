ChatGPT foi usado na escolha do desafio; Claude, na referência de interface; Codex, no planejamento, implementação e verificações. A narrativa reúne o contexto fornecido pelo candidato e os resultados observados nesta execução. Não existe exportação automática de conversas: chat-exports/ fica reservado para exportações reais, caso sejam adicionadas. O link privado de uma conversa não substitui um arquivo acessível ao avaliador.

O Git registra a implementação e as revisões publicadas. O primeiro commit reuniu a implementação já construída; ele não representa uma sequência de pequenos commits desde o começo. Os registros históricos preservam os resultados daquele momento e não devem ser lidos como o estado atual do produto.
