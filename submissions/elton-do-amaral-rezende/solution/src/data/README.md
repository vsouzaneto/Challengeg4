# Dados preparados para o app

opportunities.generated.json contém versão derivada dos hashes, vendedores, abertas com score/fatores/ação e qualidade. evaluation.generated.json contém o resumo da avaliação exibido no método. São gerados por prepare:data/evaluate; dev e build os regeneram automaticamente.

dataset.ts fornece o contrato tipado consumido pela interface. Nenhuma conquista ou conclusão é incluída nos dados preparados: ações começam vazias e ficam no armazenamento local.
