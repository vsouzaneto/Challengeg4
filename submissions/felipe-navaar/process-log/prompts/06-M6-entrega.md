# M6 — documentação e submissão

Leia AGENTS.md, docs/PRD.md e os documentos relacionados antes de agir.

Com testes e revisão concluídos, prepare o README final usando references/submission-template.md, mantendo todos os títulos obrigatórios. Preencha setup real, lógica aprovada, resultados, limitações e process log com evidências reais. Não invente LinkedIn ou testes.
Organize pacote conforme references/CONTRIBUTING.md dentro de submissions/seu-nome/ no repositório de destino. Solicite o nome da pasta se ainda desconhecido. Não altere arquivos fora dela. Inclua dados/licença/proveniência ou instruções de obtenção reproduzíveis e adapte os caminhos.
Confirme que instruções funcionam após reorganizar. Mostre checklist final e pendências. Não criar commit, push ou PR sem autorização.

Ao encerrar: resuma alterações, verificações realizadas, saídas observadas, limitações e próximo módulo. Não avance automaticamente.
