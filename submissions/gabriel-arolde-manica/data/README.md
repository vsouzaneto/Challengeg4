# Dataset

The DealPilot prototype uses the CRM Sales Predictive Analytics dataset provided by the AI Master Challenge.

The local development environment expects the following files:

* `accounts.csv`
* `metadata.csv`
* `products.csv`
* `sales_pipeline.csv`
* `sales_teams.csv`

These files are intentionally excluded from Git through `.gitignore` because they are external dataset files.

Place the CSV files inside this directory before running the application.

The application was developed and tested using the original challenge dataset.
