# O processo no Demiurgo, só o que é do G4

Esta página mostra o desafio G4 no **Demiurgo**, o quadro de tarefas que eu uso para organizar o trabalho com agentes de IA. Só entram as tarefas do desafio G4. Nada de outro projeto.

O Demiurgo é uma aplicação local, minha. Nele cada trabalho vira uma tarefa com objetivo, critério de aceite, responsável e aprovação minha. No G4, os agentes que apareceram foram Claude Code, Codex e um modelo local (um rascunho de documentação, recusado). Gemini e outros modelos não foram usados neste desafio.

## 2. As tarefas do G4

Estado em **13/10/2026**. As 8 tarefas do projeto, em linguagem simples:

| Coluna | Tarefa | Quem faz | O que é |
| --- | --- | --- | --- |
| Concluído | `G4-RECON-01` | Claude Code | Ler o repositório do desafio e fazer a ficha dos 4 cases e das regras |
| Concluído | `G4-ESFORCO-01` | Claude Code | Estimar esforço e plano de cada case, para eu escolher |
| Concluído | `G4-003-PAINEIS-01` | Codex | Páginas por vendedor e gerente, região, preço, Kanban, anotação e status |
| Concluído | `G4-003-REDESIGN-01` | Codex | Subpáginas Gerente, Vendedor e Mapa de regiões; cartão de vendedor com avatar |
| Concluído | `G4-003-DOCS-01` | Claude Code | Documentação completa do case, com capturas reais do app |
| Concluído | `G4-INTEGRAR-DOCS-01` | Claude Code | Juntar a documentação aprovada na branch de trabalho, resolvendo conflitos |
| Em andamento | `G4-VITRINE-01` | Claude Code | Esta vitrine e o rascunho do post |
| Backlog | `G4-003-REDESIGN-02` | Codex | 2º redesign: botões, textos e a parte de metodologia dentro do app |

Uma nona tarefa faz parte do processo, mas não aparece neste quadro: `G4-LEAD-SCORER-01`, a construção do Foco (Codex, aprovada por mim em 10/10). Ela foi registrada antes de o projeto G4 existir, então ficou em outro agrupamento.

## 3. O que esta página prova, e o que não prova

**Prova:** que o trabalho foi dividido em tarefas com responsável e critério de aceite, que houve revisão de outro agente e aprovação minha, e que erros e ajustes aparecem na documentação.

**Não prova:** que o aplicativo ganha vendas. Isso nunca foi medido (ver [`fluxo-completo.md`](fluxo-completo.md), seção 9). Também não prova o tempo gasto.
