# Evidências dos três caminhos

21/09/2026, aplicação local. Textos do D2; contas, notas, sistema de férias e provedor de identidade são fictícios e identificados assim na interface. IA usa OpenRouter quando marcada. Nenhuma conta real ou mensagem externa.

## Roteiro reproduzível

1. Abrir `/fluxos`, selecionar **Recuperar acesso sem atendente**, processar com IA. Solicitar recuperação como cliente e concluir no provedor simulado. A trilha registra conclusão sem revisão de atendente.
2. Selecionar **Não resolveu: encaminhar ao suporte**. O histórico vai para atendimento preparado. Editar e aprovar resposta; o texto aprovado permanece visível, sem envio externo.
3. Selecionar **Relato de dados de outra pessoa** e processar. Assumir investigação mantém o caso aberto e não altera a conta.
4. Explorar tentativa frustrada, conta desativada, fonte indisponível e histórico concatenado. Todos impedem liberação autônoma nas condições verificadas.
5. Em `/valor`, comparar contribuição de cada processo. Reduzir o volume preparado a zero mostra que o reset isolado não sustenta os custos assumidos.
