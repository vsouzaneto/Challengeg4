## Como começar

Primeiro, suba o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

Edite `app/page.tsx` — a página atualiza sozinha.
